# 溪桥渡 · 多人走格 Demo

《渡口丢药》是一段原创动物武侠小剧情。两个客户端连接同一个世界服，在同一座渡口四方向走格，能看见彼此和同一只芦滩蛇。剧情、蛇胆和铜钱按角色保存。

## 试玩

方向键或 WASD 逐格移动。靠近后按 E 对话或调查，空格攻击。也可以点击相邻格子或格子中的交互对象。

先找客栈门口的兔药师。沿渡口中间道路往东，在芦苇边调查药箱。击退附近的蛇，带蛇胆回药师处交任务。蛇被击退后，两边客户端都会看到它消失，十秒后刷新。

## 项目

- [客户端](client/README.md) 使用 Godot 4.5 和 GDScript，包含原创地图概念图与动物角色素材。
- [服务端](server/README.md) 使用 C++20、Boost.Beast、Lua 5.4 和 MongoDB。服务端决定移动、互动、战斗与奖励。

当前切片是一张共享地图、预发角色口令、一个可重做验证的任务流程。上线部署需要部署世界服、私网 MongoDB 和 WSS 入口。
